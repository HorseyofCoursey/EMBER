          Colors are stored in your browser (localStorage) as
          presets, and never leave this page.
        

        

          To use a theme on your device (no recompiling):
          on the JSON tab, click Download,
          then copy that file into a /themes folder on the
          Cardputer's SD card (create the folder if it doesn't exist yet).
          After a reboot, it shows up as an extra option under
          Settings → Theme, named after whatever you typed
          in the preset field above.
        

        

          To contribute a theme back to the project (gets it
          built in for everyone, not just your SD card): switch to the
          main.cpp tab instead, copy the struct, and open a
          PR or issue on GitHub with it.
